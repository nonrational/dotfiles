Which variant is on-register, and which SKILL.md rule decides it? The first sentence is the same in both; the difference is the sentence that follows it.

## rule

Keep the "I". Agentless policy prose loses the pledge. Narrative too: "A month later a file landed in that repo that bans the opener" hides who banned it behind a timeline. "So I banned it."

## before

From an agent it costs nothing, and praise that costs nothing is worth exactly that. A month later a file landed in that repo that bans the opener.

## after

From an agent it costs nothing, and praise that costs nothing is worth exactly that. So I banned it.

## note

The author's review comment: no need to get the timeline so precise, and 'a file landed' is passive; say 'so I banned it'. Both sentences are verbatim. In eb76ae4 'a file landed' is a link to the commit, reduced here to its text, and the two sentences sit in different paragraphs (the second opens the next one); the pair puts them side by side so 'So' has its antecedent.
